# US/SCOREBOARD — 미국 주식 스코어보드

S&P 500 종목에 종합 점수(0~100)와 근거를 보여주는 판단 보조 도구.
GitHub Pages(정적 사이트) + GitHub Actions(데이터 수집)로 돌아가며 서버가 없다.

> 투자 판단의 책임은 본인에게 있으며, 본 정보는 투자 권유가 아니다.

**처음 쓰는 분은 [사용설명서](사용설명서.md)부터** — 화면 보는 법, API 키 발급, 운영 방법이 있다.

## 화면

| 탭 | 내용 |
|----|------|
| 추천 순위 | 점수, 전일 대비, 뉴스 전망, 위험, 실시간 주가. 상위 종목 섹터 편중 경고, 거래대금 필터 |
| 오늘 밤 | 매수 후보 5개·매도 후보 5개. 종합 점수 + 뉴스 전망 가감점, 업종당 최대 2개, 거래대금 적은 종목 제외 |
| 내 주식 | 보유 종목·수량·평균 매수가를 직접 입력해 평가손익을 보고, 유명 투자자 경향·점수·뉴스를 합쳐 ‘계속 보유 우호 / 중립 / 비중 축소 검토’ 의견을 표시. 입력값은 그 브라우저에만 저장. 증권사(5대 증권사)별로 묶어 보고 매매·환전 수수료를 반영한 ‘수수료 감안 손익’ 표시. 증권사 앱 해외주식 잔고 캡처를 올리면 Claude(이미지 인식)가 읽어 확인 후 추가 — 사용자의 Claude 키로 브라우저가 직접 호출 |
| 종목 상세 | 주가 차트(1개월~5년, 50·200일 이동평균, 직접 입력한 목표주가 점선), 쉬운 설명·호재 여부·방향 전망(Claude), 위험·타이밍(베타·최대 낙폭·변동성), 요인별 점수, 해자 요약, 보유 투자자, 최근 뉴스 |
| 투자자 | 유명 투자자 10명의 13F 포트폴리오, 직전 분기 대비 변화, 관련 뉴스·발언 요약, 투자 성향(공격적/균형형/보수적 — 집중도 40%·평균 베타 35%·매매 활발도 25%로 계산한 참고치) |
| 뉴스 | 언론사 8곳 헤드라인, 한국어 한 줄 풀이, 호재/악재·사건 유형 필터 |
| 일정 | 실적 발표일(자동), FOMC·CPI 등 거시 일정(직접 입력) |
| 시장 | 시장 국면(금리·물가·VIX·고용·S&P 500 추세)과 점수 보정 계수, 금리·환율·유가 등 지표 |
| 검증 | 모멘텀 전략 백테스트, 종합 점수 상위 20개의 전진 검증 기록 |
| 수수료 | 국내 5개 증권사 기준 환전 비용·매매 수수료 계산기 |

## 점수 구성 (config/weights.yaml)

| 구성 요소 | 가중치 | 입력 |
|-----------|--------|------|
| 성장·수익성 | 20% | 매출·EPS 성장률, 영업이익률, 마진 추세, ROE, ROIC, 어닝 서프라이즈 |
| 재무 건전성 | 10% | 부채비율, 이자보상배율, EV/FCF, 유동비율 |
| 밸류에이션 | 13% | PER, Forward PER, PSR, EV/EBITDA |
| 모멘텀·추세 | 10% | 13·26주 수익률, S&P 500 대비 상대 강도, 52주 범위 내 위치, 200일선 대비, 50·200일선 교차 |
| 투자자 포지션 | 12% | 13F: 신규 > 확대 > 유지 > 축소 > 전량 매도, 비중·동시 매수 가산 |
| 뉴스 감성 | 10% | Claude 가 최근 7일 헤드라인으로 매긴 감성 점수 |
| 수급·주주 환원 | 10% | 내부자 순매수 심리(MSPR), 자사주 매입/시총, 주식 수 증가율(희석), 주식 보상 비용/시총 |
| 애널리스트 의견 | 5% | 추천 의견 수준과 3개월 변화 (EPS 추정치·목표주가는 유료라 대체) |
| 경쟁 우위(해자) | 10% | 10-K 사업 설명을 Claude(Haiku)가 읽고 매긴 0~100점 (`config/moat.json`) |

최종 점수 = 종목 점수 × **시장 국면 보정 계수(0.8~1.1)**. 계수는 FRED·Yahoo 지표(VIX, 장단기 금리차, 물가 추세,
10년 금리 변화, S&P 500 200일선, 실업률)를 점수로 매겨 자동 계산한다 (`analysis/regime.py`, 규칙은 임의값).

가중치는 출발점으로 잡은 임의값이다. 지표는 같은 섹터 안 백분위로 정규화하고,
자료가 없는 항목은 0점이 아니라 빼고 나머지 가중치를 다시 나눈다.
베타·최대 낙폭·변동성·거래대금·52주 고점 대비는 점수에 넣지 않고 위험 표시로만 쓴다.

## 필요한 키

| 이름 | 용도 | 없으면 |
|------|------|--------|
| `FINNHUB_API_KEY` | 재무 지표, 시세, 실적 일정 ([finnhub.io](https://finnhub.io/register) 무료) | 점수가 샘플로 남는다 |
| `ANTHROPIC_API_KEY` | 쉬운 설명, 호재 판단, 전망, 투자자 동향 요약 (사용량 과금) | 그 기능만 비어 있다 |
| `SEC_USER_AGENT` | 13F 수집. SEC 가 연락처를 요구한다 (예: `my-app name@example.com`) | 투자자 탭이 갱신되지 않는다 |

로컬은 `.env`, 배포는 GitHub 저장소의 **Settings → Secrets and variables → Actions** 에 같은 이름으로 넣는다.
**비용**: Finnhub·SEC·GitHub 는 무료이고 Claude API 만 사용량만큼 과금된다.
`config/settings.yaml` 의 `llm` 항목: 헤드라인 풀이는 `claude-haiku-5-5`, 종목 분석·투자자 요약은
`claude-sonnet-5-5`. 하루 종목 분석 상한(`max_stocks_per_day: 20`)과 같은 종목 재분석 최소 간격(12시간)이
비용 상한 역할을 한다. 더 줄이려면 `model` 도 `claude-haiku-5-5` 로 바꾼다. (실제 청구액은 측정하지 못한 추정이다. Claude 콘솔의 사용량 화면에서 확인한다.)

## 로그인 (가벼운 잠금)

`web/auth.json` 에 계정이 있으면 로그인해야 화면이 보이고, 관리자(admin)는 계정 승인 권한을 갖는다. Claude 키를 쓰는 AI 기능(캡처 읽기·포트폴리오 진단·종목 다시 분석)은 **로그인한 누구나 자기 키를 입력해** 쓸 수 있고, 키는 그 브라우저에만 저장되며 비용도 본인 키로 과금된다. 운영자 키와는 무관하다.
계정 추가: `python tools/users.py add 아이디 [--admin]` 실행 후 커밋·푸시. 비밀번호는 PBKDF2 해시로만 저장된다.

**가입 신청**: 로그인 화면의 ‘가입 신청’에서 아이디·비밀번호(8자 이상)를 정하면 브라우저가 해시를 만들어 ‘신청 코드’를 보여 준다.
가입자가 그 코드를 관리자에게 보내면 관리자가 `python tools/users.py approve 신청코드` 로 승인하고 커밋·푸시한다.
신청으로는 항상 일반 계정만 만들어지고 관리자 권한은 줄 수 없다. 서버가 없어 자동 저장은 불가능하다.

**한계**: 정적 사이트라 서버 인증이 아니다. `auth.json` 이 공개돼 있어 해시를 가져가 오프라인으로 맞춰 볼 수 있고
(숫자 4자리 같은 짧은 비밀번호는 몇 초 만에 풀린다), `data/*.json` 은 로그인 없이도 주소로 열린다.
진짜 접근 통제가 필요하면 Cloudflare Access 같은 서버 쪽 로그인을 쓴다.
관리자 서버 키(`ANTHROPIC_API_KEY`)는 GitHub Secret 에만 있고 사이트에는 들어가지 않으므로 방문자가 쓸 수 없다.

## AI 비용 상한

`config/settings.yaml` 의 `llm.budget_usd`(기본 $8)가 이 프로젝트의 누적 Claude 비용 상한이다. 호출 전에 최악의 비용을
계산해 상한을 넘을 것 같으면 보내지 않고, 사용액은 `web/data/usage.json` 에 쌓인다. 콘솔(console.anthropic.com)의
월 한도도 함께 걸어 두는 것이 가장 확실하다.

## 갱신 주기

| 데이터 | 방식 | 지연 |
|--------|------|------|
| 주가 | 브라우저가 사용자 키로 Finnhub 웹소켓 구독 (화면에 보이는 50개) | 체결 즉시 |
| 뉴스 | 키가 있으면 브라우저가 1분마다 직접 확인 + Actions 가 10분마다 수집 | 1분 / 10분 이상 |
| 쉬운 설명·전망 | 뉴스 수집 때 새 뉴스가 붙은 종목만 | 10분 이상 |
| 점수·13F·실적 일정 | 평일 21:30 UTC (미국 장 마감 후) | 하루 1회 |

GitHub Actions 예약 실행은 정시가 보장되지 않아 몇 분에서 수십 분 늦을 수 있다.

## 배포 (GitHub)

1. **공개** 저장소의 `main` 에 올린다. (비공개는 무료 플랜에서 Pages 를 쓸 수 없고 Actions 시간도 부족하다)
2. 위 표의 키 세 개를 저장소 Secret 으로 등록한다.
3. 워크플로가 돌면 `gh-pages` 브랜치가 생긴다. 첫 실행은 S&P 500 전체 수집으로 약 35분.
4. **Settings → Pages → Deploy from a branch → `gh-pages` / `(root)`**.
5. 사이트의 설정 탭에 Finnhub 키를 넣으면 실시간 주가가 켜진다 (그 브라우저에만 저장).

공개 저장소에서 60일간 커밋이 없으면 GitHub 가 예약 실행을 끈다. Actions 탭에서 다시 켠다.

| 명령 | 내용 | 출처 | 주기 |
|------|------|------|------|
| `prices` | 가격 이력 → 이동평균·최대 낙폭·변동성, 종목별 차트 파일(`web/data/prices/`), 백테스트용 주간 가격 | Yahoo Finance 차트(키 없음, 비공식) | 매일 |
| `market` | 시장 국면 계수와 지표 | FRED(키 없는 CSV), Yahoo | 매일 |
| `xbrl` | 주식 수 증가율(희석), 주식 보상·자사주 매입 / 시가총액 | SEC XBRL | 주 1회 |
| `flow` | 내부자 순매수 심리, 애널리스트 추천 의견 변화 | Finnhub 무료 | 주 1회 |
| `moat` | 10-K 사업 설명 → 해자 점수·근거 | SEC 10-K + Claude Haiku | 새 종목·1년 지난 10-K 만 |

Yahoo 는 비공식 주소라 막히면 이전 값을 유지하고 로그만 남긴다.

## 아직 없는 것

- **애널리스트 EPS 추정치 변화·목표주가**: Finnhub 무료 플랜에서는 403 이다 (유료 전용). 무료로 받을 수 있는 공식 출처가 없어
  종목 상세에서 목표주가를 **직접 입력**하게 했고, 추천 의견(매수·보유·매도) 변화로 대체했다.
- 종목 간 상관관계, 시장 국면별 성장주 감점 같은 업종별 차등 보정
- 종합 점수 전체의 과거 백테스트 (과거 시점의 재무·뉴스 자료를 무료로 구할 수 없음 — 전진 검증으로 쌓는 중)
- 거시 일정 자동 수집 — 지금은 `config/events.yaml` 에 직접 적는다

## 알아 둘 한계

- **전망은 예측이 아니다.** 헤드라인과 요약만 보고 만든 추정이며 기사 본문은 읽지 않는다. 화면에도 참고용이라고 표시한다.
- **13F** 는 분기 말 기준, 최대 45일 지연, 매수 포지션만 공개된다. 이미 팔았을 수 있다. 옵션 행은 점수에서 뺀다.
- **증권사 수수료** 기본값은 이벤트를 적용하지 않은 일반적 표준 수준을 넣은 것이며 각 사 공지로 확인하지 못했다. `config/brokers.yaml` 이나 화면의 표에서 본인 요율로 고쳐 쓴다.
- 헤드라인 → 종목 매핑은 회사명 일치 방식이라 누락·오탐이 있다. 장 상태 표시는 미국 공휴일을 반영하지 않는다.
- 투자자 관련 뉴스는 이름 검색 결과라 동명이인이나 무관한 기사가 섞일 수 있다.
- 다른 사람에게 공개하거나 유료로 제공하면 한국에서는 유사투자자문업 신고 등 규제 대상이 될 수 있다. 종목별 방향 전망을 보여주는 만큼 공개 전 전문가 확인이 필요하다.
