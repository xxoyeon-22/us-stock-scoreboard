#종목섹터 점수전일 대비 펀더멘털밸류에이션 주가등락률

표시할 종목이 없습니다.

    실시간 시세 (Finnhub API 키)

    키는 이 브라우저에만 저장되고(localStorage) finnhub.io 로만 전송됩니다. 저장소나 이 사이트 서버에는 올라가지 않습니다. 무료 키는 finnhub.io 에서 발급받습니다.

    갱신 주기

    • 주가 — 키가 있으면 화면에 보이는 종목(최대 50개)의 체결가를 웹소켓으로 즉시 반영
    • 이슈(뉴스) — 키가 있으면 1분마다 브라우저가 직접 새 헤드라인 확인, 없으면 약 10분마다 수집본 갱신
    • 점수 — 미국 장 마감 후 하루 1회 재계산

    점수 구성

    투자 판단의 책임은 본인에게 있으며, 본 정보는 투자 권유가 아닙니다. 점수는 공개 데이터를 기계적으로 계산한 값이고 지연·오류가 있을 수 있습니다.
