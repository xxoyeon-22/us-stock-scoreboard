    키는 이 브라우저에만 저장되고 finnhub.io 로만 전송됩니다. 저장소나 이 사이트에는 올라가지 않습니다. 무료 키는 finnhub.io 에서 발급받습니다.

    내 Claude API 키 AI 기능용 · 선택

    캡처 읽기, AI 포트폴리오 진단, 종목 ‘지금 다시 분석’은 본인의 Claude API 키로 돌아갑니다. 키는 이 브라우저에만 저장되고 api.anthropic.com 으로만 전송되며, 사이트 운영자의 키와는 무관합니다(사용료도 본인 키로 과금). 키가 없어도 나머지 기능은 모두 쓸 수 있습니다.
    키를 브라우저에 두는 방식이라 공용 컴퓨터에서는 쓰지 말고, 콘솔에서 이 키의 월 사용 한도도 걸어 두세요.

    ‘내 사용 한도’는 이 브라우저가 계산한 추정치 기준의 안전장치입니다. 한도를 넘을 것 같은 호출은 보내지 않습니다. 실제 청구액은 콘솔에서 확인하세요.

    갱신 주기
